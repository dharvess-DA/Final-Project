
# Real-World Agricultural Price Data for Analysis & Forecasting

## 📌 Project Overview
The Agricultural Price Analysis Dashboard is a comprehensive data visualization and business intelligence tool designed to track, analyze, and forecast real-world agricultural commodity prices.

The dashboard serves as a strategic tool to bridge the gap between volatile agricultural markets and informed decision-making, helping to mitigate financial risk and optimize supply chain logistics.

---

## 🎯 Objectives

 - To analyse mandi price trends of major crops across India from 2023–2025

 - To study price variations across states, districts, and markets

 - To identify seasonal fluctuations in crop prices
	
 - To compare commodity prices across different regions of India

  - To provide actionable insights for farmers, traders, and policymakers

  - To support decision-making in agricultural marketing


---

## 📂 Dataset Information
- **Source:** Kaggle – https://www.agmarknet.gov.in/ 
- **Records:** 811131 Rows 
- **Features:** 10 columns
- **Domain:** Agricultural Market

### Key Features
- State
- District Name
- Market Name
- Commodity
- Variety
- Grade
- Min Price
- Max Price
- Modal Price
- Price Date

## 🔍 Data Analysis Process
### Data Cleaning & Preprocessing
- Missing value handling
- Duplicate checking
- Outlier detection using IQR
- Feature transformation
- Data type conversion

### Exploratory Data Analysis (EDA)
- Univariate Analysis
- Bivariate Analysis
- Multivariate Analysis

### Visualizations Used
- Price Trend Over Time (Line Chart) - This chart shows how modal prices change over time for different commodities
-	Average Modal Price by Commodity (Bar Chart) - This Chart compares average prices of commodities
-	Commodity Distribution (Donut Chart) - Shows percentage contribution of each commodity in the dataset.
-	Average Modal Price by State (Map Visual) - Displays state-wise pricing on the India map
-	Commodity vs Month-wise Price Analysis (Heatmap Table) - This matrix/heatmap shows monthly price variation for each commodity.
-	Top 20 Markets by Average Modal Price (Table) - Ranks markets with highest average prices.
-	Monthly Forecast (Forecasting Visual) - This chart predicts future commodity prices.
-	Trend Decomposition (Line Chart) - These visuals separate actual prices and moving average trends. It helps to identify long-term trends.

## 💡 Key Insights
- Seasonal spikes are visible in some commodities
- Some states show significantly higher prices
- Regional price differences are clearly visible
- Certain months show seasonal peaks
- Prices expected to remain stable increasing
- Uncertainty increases in future periods
- Long-term upward and downward trends visible
- Moving average smooths fluctuations
